Inter-Regular.ttf is the unmodified static TrueType font from Inter 4.1.
Copyright and license: see Inter-LICENSE.txt.
Source: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

Expressway:
expressway.otf and expressway.ttf were supplied by the user from their installed addon.
Both files are included unmodified. Their licenses are separate from Inter's license.
Font manager tries expressway.ttf first and expressway.otf second; it also accepts
Expressway.ttf and Expressway.otf. Both TTF and OTF are supported, subject to the
client accepting the font data. Fully restart WoW after adding font files.
Installed LibSharedMedia font providers are also supported by Font manager.
