Fonts bundled with ForeverTools, each under the SIL Open Font License 1.1
(full license next to each font, in <Name>-LICENSE.txt):

- Inter-Regular.ttf: the unmodified static font from Inter 4.1
  (https://github.com/rsms/inter/releases/tag/v4.1).
- PTSansNarrow-Bold.ttf: PT Sans Narrow Bold by ParaType, unmodified
  (PT_Sans-Narrow-Web-Bold.ttf from Google Fonts). "PT Sans" and "ParaType"
  are Reserved Font Names.
- From Google Fonts (https://github.com/google/fonts), reduced to Latin and
  Cyrillic letters (and set to one weight where the source is variable) to keep
  the addon small; none of these have Reserved Font Names:
  RobotoCondensed-Medium.ttf (Roboto Condensed, weight 500),
  BarlowCondensed-SemiBold.ttf (Barlow Condensed SemiBold),
  Oswald-Medium.ttf (Oswald, weight 500),
  Rajdhani-SemiBold.ttf (Rajdhani SemiBold),
  Teko-Medium.ttf (Teko, weight 500),
  FiraSansCondensed-Medium.ttf (Fira Sans Condensed Medium),
  NotoSans-Medium.ttf (Noto Sans, weight 500, normal width).

Expressway is optional and is not included in the public addon or repository.
To use it, obtain a copy and rights suitable for your own use, place
expressway.ttf or expressway.otf here, and type /reload.
Any other .ttf or .otf you put here can be added by file name on the Fonts page.
The font manager also supports installed LibSharedMedia font providers.
